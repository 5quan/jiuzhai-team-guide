# web0.2.0

一个普通的行程参考手册，提供便捷的天气和地图查看方式。设置中可以切换九寨沟“一天精华游”或“两天慢游”。

[打开网页](http://47.111.21.130:666/) · [版本记录](CHANGELOG.md)

## 可以做什么

- 查看一天或两天的地点顺序、交通方式、预计用时和停留安排。
- 在同一画面中查看行程与地图，点击地点定位，拖动或缩放地图了解周边位置。
- 打开天气入口，方便查看景区区域的天气。
- 分享网页或打印参考行程。
- 在“AI 助手”中通过邀请码注册，保存自己的 DeepSeek Key，和固定人格「大肥鱼」聊天；回复逐句出现，可发图片，可随时停止（需管理员启用）。
- AI 会把聊天里的关键信息整理成记忆，下次还能记住你说过的事；这些记忆在“她记得的事”里可以查看和删除。

## 怎么使用

在页头“设置”中选择“一天精华游”或“两天慢游”，再切换上午、下午。两天版还可选择第一天或第二天。左侧行程从地图中部向下展示，最多显示4个地点，上下滚动查看其余内容。点击地点或交通文字，可在地图上查看对应位置和详情。

地图中当天安排的地点为红棕色；两天版另一天的地点、一天版未安排的地点为金黄色。可以在“设置”中调整入园时间；示意地图不提供实时定位导航。页面会记住本机选择的计划，分享链接也带上所选计划。

一天精华游不绑定日期，默认10:00入园，预计17:57出沟；包含五彩池返回诺日朗中心后的40分钟午餐。镜海默认车览，临时下车另预留15分钟，所有钟点均为规划估算。

详细安排见[两天行程参考表](docs/reference-itinerary.md)和[一天精华游](docs/one-day-plan.md)。网页可以直接使用，无需注册。

## 本地运行

需要Node.js 24及以上，无需安装第三方npm包。聊天配置和 IP HTTPS 部署见[AI 助手部署](docs/chat-deployment.md)。

```sh
npm start
```

打开http://localhost:3000/。

```sh
npm run check
npm test
```

部署和数据维护见[部署说明](docs/deployment.md)。
