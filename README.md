# web0.1.0

一个普通的两天行程参考手册，提供便捷的天气和地图查看方式。当前内容以九寨沟两天游览为例。

[打开网页](http://47.111.21.130:666/) · [版本记录](CHANGELOG.md)

## 可以做什么

- 查看两天的地点顺序、交通方式、预计用时和停留安排。
- 在同一画面中查看行程与地图，点击地点定位，拖动或缩放地图了解周边位置。
- 打开天气入口，方便查看景区区域的天气。
- 分享网页或打印参考行程。

## 怎么使用

先选择第一天或第二天，再切换上午、下午。左侧行程从地图中部向下展示，最多显示4个地点，上下滚动查看其余内容。点击地点或交通文字，可在地图上查看对应位置和详情。

地图中当前日期的地点为红棕色，另一天为金黄色。行程时间用于参考，可以通过页头“时间”调整入园时间；示意地图不提供实时定位导航。

当前的两天安排见[行程参考表](docs/reference-itinerary.md)。网页可以直接使用，无需注册。

## 本地运行

需要Node.js 22及以上，无需安装第三方npm包。

```sh
npm start
```

打开http://localhost:3000/。

```sh
npm run check
npm test
```

部署和数据维护见[部署说明](docs/deployment.md)。
