# 地图同屏行程与拖动优化 · 2026-10-21

## 本轮范围

保留山水手绘图片与地图点位，删除装饰山体、森林填充和宽幅沟谷色块；保留地形线条、水面、道路与栈道。左侧暖白行程面板完整呈现所选半天，取消原四地点滚动窗口。详情移至右下独立区域，入园时间设置移至页头“时间”。

低风险布局约定：常规手机保留左侧位置及原字体；高度不超过740px时收紧间距，长地点名省略显示，点击后在详情中展示完整名称；320px窄屏收起页头日期副标题，日期仍在日期切换中保留。没有修改行程数据或部署线上服务。

## 拖动实现

移动事件累积位移与双指缩放量，由requestAnimationFrame合并更新。单指拖动缓存视口尺寸、默认位置和湖泊边界数据，仅更新平移及指示箭头；松手后统一调整标签，文字宽度先集中读取再写入。移除逐字背景模糊。保留地图边界与湖泊可见性约束。

## 验证

- `npm test`：25项通过。
- `npm run check`：通过。
- `tests/landscape.browser.cjs`：72次行程点选、边界、搜索、时间设置、打印、键盘、模拟原生触控及减少动态效果通过，无页面错误。
- `tests/map-refactor.browser.cjs`：320×568、375×667、390×844、430×932、768×1024、1440×1000，共24组日期/半天布局全部站点在导航栏上方可见，无列表滚动及页面横向溢出。
- 合成拖动240次事件：26次地图样式更新；拖动中文字测量0次，结束后37次。此结果证明事件合并和测量移出拖动过程，不能作为手机实际帧率。

运行浏览器测试需安装Playwright并提供Chrome；可通过PLAYWRIGHT_MODULE指定现有模块路径。默认截图和JSON输出为`docs/map-refactor/`。
