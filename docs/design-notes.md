# 界面设计依据

用户已确认：地图为主体，占据大部分宽度，行程像山水画的题词一样浮动或重叠；按当天时间展示，点击地点定位。采用用户提供的 frontend-design 指南：https://skills.sh/anthropics/skills/frontend-design 。

## 视觉规则

- 松绿 #183D3B：标题、主操作和选中轮廓。
- 湖蓝 #0A7DA4：湖泊和当前重点地点。
- 浅水蓝 #70BED2：季节海。
- 秋褐 #BB7A3D：第二天点位及步行提示。
- 冷白 #F9FCFA：轻薄浮层。
- 雾灰 #E7EEEC：分隔与背景。

标题选用本机宋体（STSong / Songti SC / SimSun），正文选用微软雅黑 / 苹方；不加载外部字体。时间按实际顺序排列，用细分隔和间距区分段落。浮层可收起，不使用统一厚重卡片填满画面。

## 布局

地图铺满主画面，标题题在左上留白，行程题在左下留白，当前地点说明置于右下。手机将行程浮层放在地图下部，保留上部观察区域；地点定位避开浮层。地图为记忆点，其他装饰保持安静。山体层次用本地矢量轮廓表达，海子保留清楚的蓝色水面。

自查重点：路线与时长必须优先于装饰；浮层不能占用地图独立侧栏；点位名称与预计钟点不能错误关联；小屏选中地点不能被行程遮住。已通过截图复查与浏览器验证。
