# 界面设计依据

用户已确认：地图为主体，占据大部分宽度，行程像山水画的题词一样浮动或重叠；按当天时间展示，点击地点定位。采用用户提供的 frontend-design 指南：https://skills.sh/anthropics/skills/frontend-design 。

## 视觉规则

- 松绿 #183D3B：标题、主操作和选中轮廓。
- 湖蓝 #0A7DA4：湖泊和当前重点地点。
- 浅水蓝 #70BED2：季节海。
- 秋褐 #BB7A3D：第二天点位及步行提示。
- 冷白 #F9FCFA：轻薄浮层。
- 雾灰 #E7EEEC：分隔与背景。

标题选用本机宋体（STSong / Songti SC / SimSun），正文选用微软雅黑 / 苹方；不加载外部字体。时间按实际顺序排列，用细分隔和间距区分段落。浮层可收起，不使用统一厚重卡片填满画面。

## 布局

地图铺满主画面，标题题在左上留白，行程题在左下留白，当前地点说明置于右下。手机将行程浮层放在地图下部，保留上部观察区域；地点定位避开浮层。地图为记忆点，其他装饰保持安静。山体层次用本地矢量轮廓表达，海子保留清楚的蓝色水面。

自查重点：路线与时长必须优先于装饰；浮层不能占用地图独立侧栏；点位名称与预计钟点不能错误关联；小屏选中地点不能被行程遮住。已通过截图复查与浏览器验证。


## 2026年10月20日交互调整

去掉全天选项及参考图小字。地图画面最大高度720px，移动端最大700px；缩放统一限制1—2倍，手机初始1.5倍，点选日程保持当前比例。位置变化用三道蓝色水纹反馈，减少动态效果偏好下改为静态标记。

拖动、滚轮、缩放、方向键或点选地图后，行程栏只留下带预计开始时间与分钟数的列表；点行程条目恢复面板并展开单个地点，再点同一项收起详情。手机展开详情时暂隐藏入园设置，为内容留出空间。空的看点与注意事项保留标题和空白，五花海注意事项仅写“吃一根烤肠”。


## 窄幅行程与地图边界

保留松绿#183D3B、湖蓝#0A7DA4、冷白#F9FCFA与雾灰#E7EEEC，继续使用宋体标题和本地无衬线正文。地图仍为主画面；行程左对齐，名称一行，时间与分钟数另起一行。移除重复大标题、压缩交通用语，不缩小正文字号。

桌面行程210px、简览180px；手机常态最多180px且不超过半屏，简览最多154px且不超过44%屏宽。地图所有移动入口共用画布边界：图面某一轴能完整显示时居中锁定，大于视口时仅能在边缘内拖动。点击后如手机浮层遮挡定位点，浮层选择上方或下方剩余空间避让，不再把图面平移到空白处。


## 顶部合并

移除独立的品牌栏，把分享和打印并入一行小标题。日期栏只保留两天的日期和第几天，完整星期与游览摘要通过无障碍名称保留；住宿安排在下方折叠区。六档宽度实测地图起点为手机85px、桌面89px，减少重复标题和大段顶部留白，保留原字号与配色层级。


## 截图默认视野与点击箭头

用户确认移动范围按“半幅地图”计算。手机初始和日期切换采用1.6倍概览，以五花海落在横向约71%处校准参考构图；两支沟同时可见，垂直居中。桌面保持全幅概览，全图按钮仍可回到1倍。

各方向位移不超过当前比例下半幅地图，以当前比例对应的默认位置为中心。另保留至少半幅图面/视口交叠，并确保可见区域有湖泊地标，防止画布留白被拖成纯白。点击定位共用这些限制。

指向箭头采用秋褐色和白色描边，与湖蓝水纹区分，固定屏幕尺寸不随缩放变小。点击后轻动三次，随后静止保留至新的选点；水纹结束不会移除箭头。平移和缩放同步更新箭头，靠顶部时转到点位下方，减少动态效果偏好下不播放动画。
